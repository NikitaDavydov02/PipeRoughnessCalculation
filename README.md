# Описание
Проект представляет собой консольное приложение для расчёта эффективной шероховатости труб по резултатам измерений давления и потока

# Порядок работы
Сначала программа просит указать параметры расчёта, которые не изменяются от измерения к измерению, а также количество измерений.

Далее можно указать, стоит ли игнорировать (удалять из выборки) измерения с неположительными потоком или давлением и измерения, в которых выходное давление превышает входное.

Также можно указать, стоит ли удалять из выборки те измерения, расчёт по которым привёл к физически невозможным значениям шероховатости (отрицательным или превышающим диаметр трубы).

Если количество измерений в конечной выборке больше одного, то будет расчитана случайная погрешность при заданной пользователем доверительной вероятности, также программа предложит учесть систематическую погрешность, возникающую из-за несовершенства приборов/методики/справочных данных.
