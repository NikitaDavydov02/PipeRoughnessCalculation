# Описание
Проект представляет собой консольное приложение для расчёта эффективной шероховатости труб по резултатам измерений давления и потока

# Порядок работы
Параметры расчёта указываются в файле "input.xlsx", пример которого находится в папке "exe". В нём также можно указать, стоит ли игнорировать (удалять из выборки) измерения с неположительными потоком или давлением и измерения, в которых выходное давление превышает входное.

Также можно указать, стоит ли удалять из выборки те измерения, расчёт по которым привёл к физически невозможным значениям шероховатости (отрицательным или превышающим диаметр трубы).

Если количество измерений в конечной выборке больше одного, то будет расчитана случайная погрешность при заданной пользователем доверительной вероятности.

Расчёт гидравлического сопротивления в зависимости от шероховатости производиться по формуле, заданной пользователем в строке "lambda formula". По умолчанию в данной строке указана формула Альтшуля, но может быть записано любое другое выражение согласно документации к пакету NCalc и с использованием таких переменных как F (поток кг/с), rho (плотность кг/м3), viscosity (вязкость Па*с), D (диаметр, м), L (длина участка трубы, м), Re (число Рейнольдса). Также в выражении обязательно должна фигурировать roughness (относительная шероховатость). Нахождении шероховатости производится методом бисекции с точностью, заданной пользователем.
